# Jahidul Islam Sohan

I build websites for online travel agencies, and for other businesses.

For more than four years the main work has been OTA and travel-agency sites: flights, hotels, visas, packages, and umrah. Agencies usually take bookings on Facebook and by phone, or they pay a high monthly fee for a GDS API. I build the site in between. The agency keeps its own fares, seats, and service fees, and the customer books in one place.

The same work covers other software websites: admin desks, office systems, and customer portals.

## What I ship

- OTA and travel-agency websites
- Booking flows for flights, hotels, visas, packages, and umrah
- Admin desks for enquiries, quotations, invoices, and staff
- Other business websites when the product is not travel
- PHP and Laravel, Java and Spring Boot, JavaScript and TypeScript
